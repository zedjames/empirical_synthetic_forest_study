# Paper V computational artifact v1.0.0

The reviewed scientific source and two complete frozen evidence archives accompany
*Prospective Health under Declared Specifications: An Auditable Empirical-Synthetic
Forest Measurement Study*, Health, Formally Defined, Paper V, by Zed James.
The paper identifier is unchanged: https://doi.org/10.5281/zenodo.23268987.

## Contents

- `PaperV_HFD05_v1.0.0.zip`: 492 frozen scientific members plus the package manifest.
- `PaperV_HFD06_v1.0.0.zip`: 67 frozen scientific members plus the package manifest.
- `SHA256SUMS`, license and third-party notices, and the public verification records.
- `HFD05/` and `HFD06/` source directories, configurations, documentation, scientific
  checkers and bounded reference outputs. The 35 larger evidence files are present
  in the ZIP assets, not ordinary Git history.

All 536 prepared candidate files received final security and licensing inspection;
all 98 attention flags have recorded dispositions. Original scientific bytes and
both ZIP identities remain unchanged. Existing public citation, publication and
methodological documentation are preserved. The obsolete preparation-status
wrapper is omitted; current public notices supply the publication status and
licensing scope without rewriting historical scientific manifests.

## Scientific verification

The completed isolated reference-runtime reproduction passed 24/24 original stages,
and separate inspection verified 69/69 evidence checksums, the original kernel,
the original hazard posterior, and all nine predictive output identities. Publication
does not rerun the science or assert a new external reader's reproduction.

Exact-byte reference: native ARM64, Darwin 27.0.0, Python 3.9.6, NumPy 2.0.2,
Clang 21.0.0. Intel floating-point differences remain documented; cross-platform
byte identity is not claimed. Reproducibility does not establish an operational
ecological Health diagnosis or full prospective ecological validation.

private repository or private Git history is required.
