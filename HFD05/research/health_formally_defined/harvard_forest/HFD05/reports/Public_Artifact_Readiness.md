# Local publication-review artifact readiness

The deny-by-default candidate contains only the previously reviewed numerical
forest package and the explicitly enumerated corrected study source, configuration,
tables, figures, Methods, evidence and provenance. Exact filenames, sizes and
hashes are in `release/export_inventory.json`. No raw inputs, build cache,
credentials, private Lean/world sources or internal machine paths are exported.
The initial468-file export occupies317,443,501 bytes; the final inventory records
the actual completed inclusion set. This is scientific source/evidence, not a
copied repository, data bank or cache.

Original and corrected identities remain addressable. Scientific functions are
byte-preserved; operational adapters bind package-only input and source guards.
The package verifies included bytes but does not claim to reconstruct absent
private Git history. Its phase hashes still enforce original registered
scientific source bytes. Every imported research module is required to resolve
inside the package. Exact CC0 observations are retrieved separately from eight
canonical publisher URLs and checked against frozen hashes; no private raw
location is read and no unrestricted download is allowed.

Three replay tiers are actual executable commands. Tier1 checks29,240 finite
queries, Gamma deterministic/moment fixtures and actual original/corrected
generator fixtures. Tier2 audits all32,400 primary,121,500 missingness and46,656
crossmatrix cells plus adult/seedling headline support and ten source-qualified
figures. Tier3 independently reconstructs all384,128 adult prediction/score rows
and8,840 seedling transitions from freshly retrieved publisher files, regenerates
figures, and replays the full original-roster oracle. Actual stdout/stderr,
exit codes, manifest identities and elapsed time are saved in `release/replay_*.json`;
terminal readiness depends on these receipts, not command availability.

Observed initial times:Tier1 about0.54seconds, Tier2 about1.39seconds, eight-input
retrieval about4.59seconds, independent external audit about10.41seconds,
figure regeneration about0.45seconds; full corrected references about340seconds;
full oracle generation plus analysis recovery about628seconds. The oracle
generation/count-state outputs reproduced frozen bytes exactly. Its first
analysis failed because concurrent reference replay generated a declared partial
table omitted from the runtime-only allowlist. That failure is preserved;
the adapter now allows only four explicitly named generated CSV paths, rejects
all other unlisted paths, and resumes analysis on the byte-verified full census.
No scientific function, source law or count changed. Full private
primary/missingness banks remain isolated and source-hashed;
the package does not ship their roughly756MiB histories or claim that the
lightweight fixtures are a full ensemble replay. Complete corrected reference,
context and external scoring stages are exposed explicitly for fuller replay.

Public readiness is qualified: LOCAL_PUBLICATION_REVIEW_CANDIDATE, no public
publication, visibility change, release or DOI. Dataset CC0 does not confer a
license over source IP. Owner source-license/disclosure review and an authorized
public destination are still required before dissemination. This tranche prepares
and tests the local candidate; it does not authorize those external actions.
