# Context and statistical interpretation

For a single fixed joint law of target Y and nested information sigma-fields
F⊆G, fixed loss L(Y,a), and the same permissible actions, the infimum Bayes risk
using G is no larger than using F: every F-measurable action is also
G-measurable. If minimizing actions exist, the same inequality holds for their
attained risks. This inclusion proof does not require conditional independence.
It is an optimal-risk theorem, not a guarantee for a finite approximate estimator
whose prior, weighting law, target or algorithm changes between conditions.

Our full, coarse, unknown and label-only experiments use implemented approximate
estimators and distinct context mixtures. The81-world boundary roster has
context counts[7,7,7,7,7,7,13,13,13]; uniform-nine weights are not its marginal.
The earlier324-world factorial has a different uniform roster. The original
and separately registered roster-prior sensitivity remain visible; they are
not interchangeable instances of the optimal information theorem. Better finite
performance from a coarser mixture can reflect regularization, prior mismatch,
state/context dependence and numerical variation, without violating that theorem.

All corrected contexts are scored against original and corrected references,
with suites, margins and cohort identities kept separate. The original nominal
boundary balanced accuracy was partial, not operational validation. Four oracle
interfaces diagnose state/parameter interactions; supplying parameters alone
can worsen predictions. No nonnegative additive attribution is imposed.

Uncertainty categories are separate: finite-bank exactness; approximate inner
kernel Monte Carlo; reference-label ambiguity; between-state/parameter design
dispersion; observation/inference/future seed panels; paired constructed-world
bootstrap; source-support external cluster bootstrap; nonidentified entry and
latent-fate diagnostic ranges. None is silently promoted to an ecological
population confidence interval. Empty strata remain undefined. No scenario
prior or ecological posterior over semantic specifications has been inferred.

At theta0 present realization still matters. At theta1 all-success finite counts
are not kernel certainty. Single-reserve95 inference replaces the old redundant
two-component Q2 procedure without changing finite Health. All adverse and
reference-unresolved worlds remain represented.
